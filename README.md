# MKHANDI AI SCAN — Watchlist & Navigation Update

This build restores the **Profile** and **Settings** menu options and renames **Live Market Scanner** in the sidebar to **Watchlist**.

## What changed
- Added **Profile** with a browser-local display name setting.
- Added **Settings** with live scanner status, a scanner enable/disable control, and a watchlist summary.
- Renamed the sidebar destination to **Watchlist** so users manage selected assets and live analysis in one place.
- Added a clear **ENABLE LIVE MARKET SCANNER / DISABLE LIVE MARKET SCANNER** control inside Watchlist.
- Kept the current MKHANDI red, black, white and light-grey design and existing signal-analysis logic.
- The scanner remains signal/analysis-only; it does not place trades.
- Existing watchlist defaults and add/remove customisation are preserved.

## Use
1. Extract the ZIP.
2. Deploy or open `index.html` as you normally do.
3. Open **Watchlist** to add/remove assets and enable/disable live analysis.
4. Open **Settings** for scanner state and watchlist summary.
5. Open **Profile** to set the dashboard display name.

Profile name and watchlist preferences are stored locally in the browser.
